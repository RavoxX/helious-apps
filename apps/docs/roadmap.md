# Application roadmap

The original phases implemented accounts/recovery, Markdown/link handling, the browser editor, graph/analytics, Spaces/history, encrypted secrets/MFA and scoped MCP/OAuth. Desktop local folders, watching and selected-Space sync followed.

The current priority is the owner's native desktop rebuild: Windows Rust/egui, macOS SwiftUI, visible account/settings navigation and signed GitHub updating. Advanced browser features continue to be ported; see the desktop guide for differences.

Next authoring work: canvas, templates, daily-note UI and remaining editor features. Public managed Cloud deployment, trusted platform signing/notarization and final hardening are separate operational work. This repository does not ship the marketing homepage.
