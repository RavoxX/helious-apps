# Helious applications

Public application and self-hosting source: the API/server, browser workspace, native Windows/macOS apps and shared packages. The marketing website and its assets are not included.

Start with [installation](./getting-started), [desktop apps](./desktop), [email setup](./email) and [security](./security). Verified accounts, password recovery, Spaces/history, graph/analytics, encrypted secrets/MFA and scoped MCP/OAuth are implemented in the server/web workspace. Native feature differences are documented in the desktop guide.

Managed Cloud will use https://helious.work; it is not live yet. Self-hosting and offline local folders do not depend on that service. Canvas, templates and daily-note UI remain future work while native desktop rebuilding takes priority.
